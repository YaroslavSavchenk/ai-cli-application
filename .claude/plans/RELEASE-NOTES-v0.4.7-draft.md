# v0.4.7 — Fable 5.2 and Haiku 5.5

- **Two new models in the Model list.** Fable 5.2 and Haiku 5.5 now head
  their families, next to Opus 5.5 and Sonnet 5.5. Fable 5.1 and Haiku 4.5
  move to "Older models" and stay available.
- **A project set to plain "Fable" or "Haiku" now starts the newest one**
  (Fable 5.2, Haiku 5.5), the same models Claude Code itself picks for those
  names. A project that names a specific version keeps it.

Verified with Claude Code 2.1.325.

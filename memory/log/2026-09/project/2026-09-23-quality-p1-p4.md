# 2026-09-23 — P1–P4: the speed work the user picked from P0

The user picked four of P0's ten proposals ([[2026-09-23-quality-p0-measurements]]);
the tab switch (P5) waits for this re-measurement. Three agents in parallel
(backend, UI, cross-cutting), security + scope review, one fix round,
`/verify-terminal` V1–V9 PASS (a real `claude` session with its permission
prompt included; WebGL alive after every move).

| | Before (HEAD re-run) | After |
| --- | --- | --- |
| Split 2→3 replay / longest frame gap | 3.84 MB / 271 ms | 0.34 MB (new pane only) / 166 ms |
| Close 3→2 replay / gap | 2.56 MB / 162 ms | 0 / 42 ms |
| Tab switch 1→4 replay / gap | 5.12 MB / ~240 ms | 1.37 MB / ~220 ms |
| Warm load, bytes | ~1.13 MB | 8 kB |
| Resizes per pane at boot | 2 | 1 (0 when the size already matches) |
| Idle requests / log per minute | 42 / 64 lines | 22 / 1 line |

- **P1** `replayTail` (`server/sessions-output.ts`): an attach sends the last
  `REPLAY_MAX_LINES` = `SCROLLBACK_LINES` (5000, now in `shared/`) + 200
  lines, cut after a `\n`; the ring still keeps 1 MiB. Output of very long
  lines gains nothing (lines counted by `\n`, not by wrapped rows).
- **P2** `relayout` + `pane-reuse-model.ts`: a pane whose content stays in
  the tab keeps its card, xterm and socket through split/close/extract/swap;
  only a new pane attaches. Moving a card with `insertBefore` keeps its
  WebGL context.
- **P3** `initPanes` runs after the chrome's first render (the first fit had
  measured the grid before the Files panel and the tab strip were drawn);
  `/assets/*` is `immutable` for a year, the HTML stays `no-store`.
- **P4** the poll summary (`server/poll-log.ts`): the user asked for quieter
  poll lines; the default level being `debug`, "demote to debug" would have
  changed nothing, so a successful poll is counted and summarised once a
  minute, a failed or ≥ 1 s poll is written at once
  ([[log-everything]] amended).

## Worth remembering

- A tab switch still costs ~200–250 ms: with the bytes gone, xterm parsing
  4 × 5200 lines is the cost. That is P5's question (keep inactive tabs
  alive), not more trimming.
- "Log at debug" means nothing when debug is the default level — check the
  level before promising a quieter log.

# 2026-09-23 — quality track opened; Q0: how code is written here

After the restructure day ([[2026-09-23-repo-optimisation]]) the user asked
whether everything was now well optimised and object-oriented. Answered
honestly: structurally mostly; not object-oriented and not meant to be
(functions first, classes for things with a lifetime); the app itself not
made faster. The user: code quality first, then optimisation, and
guidelines "dat vanaf volgende keer dit wel op zo'n manier gedaan wordt".

Decided the same day (plan `.claude/plans/PLAN-QUALITY.md`, phrase "begin
aan de kwaliteit", CLAUDE.md now names three tracks): relative times read
"5 minutes ago" everywhere; for duplicates that differ the orchestrator
picks the most correct variant with a test per edge; speed is measured
first (P0) and the user picks.

## Q0 — landed

- `CONTRIBUTING.md` at the root: the stack's limits (erasable syntax,
  strict, no `any`), functions first / classes for lifetimes / `extends` only
  for error classes, module shapes (`*-model.ts` pure, stores, views, route
  families), one home per helper, no dead code, headers and WHY-comments,
  errors-copy-logging, the hard constraints. Every claim checked against the
  code (two corrected: older classes still use TS `private`; error classes
  extend `Error`).
- `tests/repo/no-duplicate-code.test.ts`: identical normalised function
  bodies (≥ 80 chars) in two source files fail. It found four pairs on its
  first run — two known (`plainObject`, `isPort`) and two new
  (`closeDialog` = `closeFolderPicker`, `clampBehaviour` = `clampStatusLine`);
  they sit in a shrink-only `KNOWN` list that Q1 empties.
- Cited from `CLAUDE.md`, `README.md` § Repository layout, the developer
  agents, the fixer and janitor, the scope-reviewer (it reviews against the
  file) and `/dev-flow`.

## Q1–Q4 — landed the same evening

Four agents in parallel on disjoint files, then security + scope review,
one fix round. Suite 3712 → 3734 (every new test pins an edge).

- **Q1, duplicates that differ**, each with the correct variant and a test:
  one `relativeTime` ("5 minutes ago", decision 1) replaces `fmtAgo` and the
  GitHub list's `relTime`; `fileName` (a trailing `/` names the folder);
  `joinPath` (no `//`); `projectsDirOf`; strict `numberOrNull`; `statusOf`;
  `isClaudeCommand`/`commandBase` in `shared/` cut on `/` AND `\`, now used
  by EVERY "which tool is this" check (`--session-id`, `--settings`, keys,
  the cmd.exe tail — they used to disagree); `server/sanitise.ts` for the
  deliberate twins; `isPort`/`VERSION_SHAPE`/`FULL_HASH` in `shared/`;
  `home-store.ts` with its I/O passed in; `ModalSlot`; `clampToggles`. The
  duplicate guard's `KNOWN` list is empty. The fix round moved formatting
  out of `util.ts` into a pure `format-model.ts` (no model imports DOM
  helpers any more) and fixed a Q1 regression: a history row with no
  readable time capitalised a custom command.
- **Q2**: every sleep that stood in for a condition waits for it; a clock
  seam in `dnd.ts` replaces six `sleep(90)`; `waitForLogQuiet`; every
  remaining "nothing happens" wait is a named constant tied to the poll.
  Some old waits proved nothing (a `calls === 1` check that passed without
  the second request); they do now.
- **Q3**: the watcher re-reads a meta file when its size changes too — the
  race test fails on the old code, a second test proves a broken file is not
  re-read every poll.
- **Q4**: the Files panel's `ctx` kept (a shared state object would let
  every piece write every field) and typed; the four copies of the
  ui-filedrop setup became one `world` fixture (−281 lines).

Visible text changes (decision 1): sessions list, resume picker and GitHub

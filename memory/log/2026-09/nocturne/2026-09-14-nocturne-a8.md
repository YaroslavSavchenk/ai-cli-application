# 2026-09-14 — Nocturne A8: UI gate LANDED, Legacy alias layer deleted

Part A8 of [[nocturne-full-switch]] (`.claude/PLAN-NOCTURNE.md`), started on
the user's "continue met a8". Goal: every surface still wearing the Legacy
role-token names moves onto the Nocturne primitives, the theme popover UI
goes, the `LEGACY ALIAS LAYER` block and marker in `tokens.css` are deleted,
and the whole UI is compared side by side against the v3 handoff.

v3 handoff has NO design for the shortcuts overlay, the update toast, the
restart confirmation, the boot overlay or the boot/restart takeover panels;
the theme popover was unreachable since A2 (`initTheme` had no importer).

(and paused on the user's word). B12 was committed alone: whole-file B12
paths staged, shared files hunk-filtered (`git diff -U0` split, C1 hunks

`git update-index --cacheinfo`. The staged diff was then applied to a clean
`git worktree` and typecheck + build + suite run THERE. Three failures there
(boot banner commit, REAL restart ×2) also fail in a HEAD-only worktree:
a linked worktree has no resolvable server commit — environment, not code.

## Lessons

- `realpath` on drvfs keeps the REQUEST's case (`/mnt/c/windows` stays
  lower-case), so any string compare against a realpath'd anchor is
  bypassable by a case variant there. Compare by `dev:ino` — every case
  spelling of `/mnt/c/Windows` measured the same `67:281474976714177`.
- drvfs inode numbers are NTFS `seq << 48 | record`: past seq 31 they exceed
  2^53, so `lstat` without `{ bigint: true }` rounds neighbours together.
- A string check on "the registered path" and one on "its realpath" still
  miss a symlink in the MIDDLE of the chain; walking the chain like the
  kernel does and recording every entry closes the whole class.
- A test-gate copy goes stale while fixes land: its "still open" finding
  was already fixed — re-read the tree before relaying a gate's survivors.

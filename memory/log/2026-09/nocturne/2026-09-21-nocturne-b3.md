## What the reviews found

- **Security (MUST):** a repository configured as a partial clone with one
  missing object made `git log --numstat`, the `rev-parse` hash gate and B2's
  SHIPPED `git diff --numstat` run the transport program the repository named
  — code execution from opening a tab. Fix: `GIT_NO_LAZY_FETCH=1` in the
  shared env, marker tests with a non-vacuity half on both routes' files.
- **Scope (MUST):** `git log -1 <hash> -- <path>` walked to an ANCESTOR and
  answered with its diff under the requested hash. Fix: `--no-walk`. The
  existing test asked the root commit and could not see it.
- Security (SHOULD): the gpg "not executed" proof was vacuous (unsigned
  fixture commits) → a hand-written commit object with a `gpgsig` header.
- Frontend scope: a commit row was a dead click until the Changes answer
  landed (now opens and resolves the repository root late); a stale flight
  marker left `Loading…` for 5 s after a root change; `Show more` swallowed
  during a poll (two flight markers now); every diff answer rebuilt the whole
  view (one block repainted now); a parameter named `repoRoot` that must carry
  the request root. Frontend security: a synchronous `URIError` from a lone
  surrogate hung a block on `Loading…`; bidi override in a file name.
- **Gates:** backend FULL probe 102 mutants — 75 killed, 15 gaps closed with 8
  new tests, 12 equivalent with a measured reason — and ONE real defect: the
  8 KiB body cap cut an emoji in half (`capChars` on a pre-sliced string

## Lessons

- [[fifo-open-blocks-main-thread]]: `O_NOFOLLOW` + `isFile()` is not a
  FIFO defence; add `O_NONBLOCK`, and test with a real `mkfifo`.
- A mutation gate that reads the security auditor's "no test for X" list
  pays off: three of the four new killers came from that list.
- Coverage gaps left open (test-engineer): `index.ts` watcher wiring on the
  standby path, boot-wipe + re-report for the same id, a DOM/CSS check of
  the amber tone, `setTelemetry` with zero clients.

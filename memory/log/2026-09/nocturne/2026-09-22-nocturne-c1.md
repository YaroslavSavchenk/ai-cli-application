# 2026-09-22 — Nocturne C1 LANDED: the peek mascot at the edge of the monitor

User: "Begin aan C1 nu en daarna gaan wij hem releasen" (v0.4.0 prepared in
B8, held until C1). Decisions 12–16 asked first ([[c1-peek-mascot]]).
Spec `.claude/plans/nocturne/PLAN-C1.md`. Phase 1 (the standalone page) had
landed 2026-09-15 ([[2026-09-15-peek-mascot-phase1]]).

## What landed

- **Signal (server):** `SessionInfo.turnUnseen` (set only on a working →
  waiting move of the B11 turn; cleared by `seen`, by working, at exit) and
  `pendingSince` (when `attention || turnUnseen` became true). The client
  acks `turnUnseen` exactly where it acks a BEL (`markSeenLocally`).
- **Page:** `/mascot.html` now carries the token (same no-store + frame
  protection + Host/Origin checks as `/`), `web/src/mascot/feed.ts` polls
  sessions + prefs every 2 s, a rise shows only after holding 1.5 s (a turn
  ending in the watched pane is acked first — no flash), reports
  `mascot-count` + click-through rects and, after a click's reaction,
  `mascot-open`; reduced motion stops every animation.
- **Main page:** `focus-session` from the host (strict parse in
  `host-bridge.ts`) → that session's tab and pane, which acks it.
- **Toggle:** `prefs.mascot = { enabled }`, Settings → Preferences `Peek
  mascot` (the v3 Notifications slot), default ON; the server validates the
  shape, and the client drops a bad stored value before any save so a
  hand-edited prefs.json cannot block every other preference.
- **Host overlay** (`launcher/host/AiSessionManagerHost.cs`): a TopMost,
  toolwindow, no-activate borderless form with a transparent WebView2 on the
  main window's environment, placed at the right edge of the app window's
  monitor, navigation locked to exactly `/mascot.html`, strict string
  messages; its window REGION is the union of the reported rects (empty at
  count 0 — never `Hide()`, because a hidden WebView2 gets Chromium's
  intensive throttling after 5 min); `mascot-open` → main window to the
  front + `focus-session`; reloads a crashed page (3 per 10 min); re-places
  on display changes.

## Lessons

- Two sessions in one checkout: never `git add -A`; stage your own paths,
  unstage what a peer's plain `git commit` would sweep, and say so to the
  peer. A peer can ask to stop your agents — its developer was editing the
  same files.
- A hidden WebView2 is a throttled one: an overlay that must react within
  seconds after long idle stays shown with an empty region.

## Lessons

- **The boundary of a delete is "may I remove an entry OF this folder"**,
  not "is the thing it points at inside" — realpath the parent, never the
  final component. Deleting a realpath'd path deletes a symlink's target.
- **"Never an anchor" needs both directions**: equal AND contains. A rule
  that only compares equality lets the parent row take the anchor with it.
- **Sync filesystem work on the server is a PTY freeze**: 20k files = 0.4 s
  of no output, no resize, no presence ping. Async, sequential.
- **A dialog that returns focus to a row that is about to be repainted
  away** leaves the keyboard on `<body>`; promise the focus to a survivor.
- **A comment can overclaim what a realpath can do** (bind mounts); the
  gate's tripwire mutants (`throw` in a branch) find dead code cheaply.
- **Concurrent git writes flake `tests/git-changes.test.ts`** (`.git/index`
  mtime); no `git add` while an agent runs the suite.

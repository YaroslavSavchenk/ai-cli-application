## A10 decisions (user, 2026-09-15)

One tab per root folder (`Home` / project name), files as panes with the
1/2/4 layouts; free mixing terminal | file | diff in one tab; a FIXED `Home`
tab always first, never draggable/closable, may stand empty; drags = reorder
tabs, swap panes, drag a Files row onto a pane edge (split) / file-pane centre
(replace) / terminal centre (refused) / folder chip (append) / empty tab;
last file pane closes a project tab unless it holds a terminal; the A6
`Changes in <hash>` diff stays as a third pane kind. Orchestrator defaults:
new sessions keep their own tab; file from a project-less session → `Home`;
chords ctrl+alt+enter (focused Files row → split) and ctrl+alt+w (close file
pane; nothing on a terminal, swallowed).

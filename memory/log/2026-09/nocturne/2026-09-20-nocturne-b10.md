## Lessons

- **A check "at the end" is a check too late for anything created on the
  way.** Both the anchor re-check and the data-dir refusal had to move
  inside the mkdir loop. Spec bug, caught by measuring, not reading.
- **An exception message is untrusted output.** `Path.GetFullPath` quotes
  the path in `ArgumentException`; the host's "never a path" test grepped
  variable names and could not see it. Log the class.
- **A timer nobody measured is dead weight.** The 250 ms linger "saving the
  413" did nothing; `connection: close` did the whole job.
- **A mock's inert Esc becomes a real bug at real scale** — A9's blocking
  card was fine at 60 ms × N; B10's 2000-file drop needed `Hide`.
- **Same working tree, two sessions**: name your files up front, freeze the
  other's dirs, exchange landing hashes. It worked.

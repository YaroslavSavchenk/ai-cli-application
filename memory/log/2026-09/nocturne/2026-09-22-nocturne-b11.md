  `<parent>/<uuid>.jsonl`, derived from the tracked subagents dir, same
  realpath boundary re-checked per poll, `O_NOFOLLOW`, file realpath must

  `<local-command-*>`) and `isMeta` lines do not count — measured on this

## Lessons

- A transcript's "last line" is not the turn: local slash commands write
  user lines without starting a turn, and an interrupt is a user line that
  ENDS one. Measure the real line shapes before writing the rule.
- A boundary that requires the parent to exist silently breaks the first
  use of a new folder — the untested day-one path. Test the first session
  in a folder nobody has opened.

## What the reviews found

- The spec's `openRestartConfirm('settings')` assumption was false
  (`'settings'` = restart mode, always); the developer worked around it
  with `'pill'` and flagged it; fixed with a dedicated source.
- D3 had two blockers: the runtime fetch was not awaited before `loadUi`
  (a slow answer read an F5 as a new run AND wrote `run:null` into the bag),
  and the restart/update reload produces a NEW `startedAt` — the one case
  D3 keeps. Fixed: `await runtimeChecked`, unknown run keeps, a known stamp
  is never nulled, `st.setRunStamp(child.startedAt)` before
  `location.reload()`.
- The 2b reviewer then showed the switch would be INVISIBLE: localStorage is
  per origin including the port, and a fresh start auto-picked a new port,
  so the layout was gone whatever the switch said. User's call (D5): the
  backend keeps its last port; auto-pick becomes the fallback. Side effect:
  `Reopen tabs on start` ON now restores file tabs across app starts, which
  was never true before.
- Phase 1: `checkNow()`'s `if (running) return` answered the OLD status when
  a click landed inside the periodic run; the access-log gate widening
  (`reason=` on 2xx) was reverted in favour of a separate `note=` channel.

## Lessons

- A spec line that names another module's API (`openRestartConfirm('settings')
  … already in update mode`) is a claim to verify by reading, not a fact;
  the developer read it, worked around it and flagged it — the right shape.
- "Where does the persisted thing live and what is its key?" — localStorage
  keyed by origin made a carefully specified switch inert; the reviewer who
  asked "is this observable at all?" earned the fifth decision.
- Three parallel developers + three parallel test-engineers share ONE
  scratchpad: a helper script was overwritten mid-run. Brief parallel agents
  to use a subfolder each.
- The default shell node is v18 and cannot run the `.ts` suite; every
  brief needs the nvm Node 24 `PATH` line.
- The FIFO rule ([[fifo-open-blocks-main-thread]]) was missed a THIRD time
  by a new data-dir reader; a brief that adds a data-dir file must name the
  rule, and the older readers are now a backlog item.
- A gate agent put its mutant backups in `scratchpad/` INSIDE the repo (an
  untracked top-level folder that `git add -A` would have staged); briefs
  must name the session scratchpad path, and the orchestrator checks
  `git status` for a stray top-level folder before staging.
- A synchronous FIFO guard cannot be raced against a timer in the same
  process — the open freezes the loop, and `--test-timeout` cannot cut it
  either; prove a non-blocking read in a child process with a hard timeout.

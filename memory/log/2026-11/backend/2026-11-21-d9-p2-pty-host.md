# 2026-11-21 — D9 P2: the pty-host process and its wire

Part of [[pty-host-session-survival]] (spec `.claude/plans/nocturne/PLAN-D9.md`).
Not yet wired into the backend (P3).

## Done

- `server/pty-host-{main,server,wire}.ts` + `server/pty-host-client.ts`
  (flat `server/`, CONTRIBUTING over the spec's first folder idea): a
  detached pty-host per data dir over `pty-table.ts`; unix socket
  `pty-host.sock` (0600), token in `pty-host.json` (0600), lock name secret
  `pty-host.lockname`, own `pty-host.log` (no bytes/env/argv/token).
- Wire `u32 len | u8 kind | payload` (control JSON / output / input /
  binary snapshot), cap 1 MiB + 64, 256 KiB pieces on char boundaries.
- Roles: owner seat (exclusive, takeover demotes + destroys the old one),
  probe (`list-count`, `shutdown-if-empty`); 16 pending connections max.
- Lifetime: orphan grace 10 min (decision 26), idle exit 60 s, SIGTERM /
  SIGINT / uncaught ⇒ shutdown-all; backpressure pause at 8 MiB.
- Data dir: the backend fchmods an owned data dir to 0700; the installer
  creates it 0700 (a fresh install made it 0755 ⇒ the pty-host would
  refuse forever). One `envMs` (loud fallback, floor, cap) in config.ts.

## Review

Security: a replaced owner kept owner rights on a half-open socket
(rights now from the seat); the client trusted the data dir's files
(now checked: uid, mode, type); the abstract-socket instance lock was
named from uid + path ⇒ two WSL distros with the same user COLLIDE (no
attacker needed) — now named from a 128-bit secret in the 0700 dir.
Full mutation gate: 156 mutants, 63 gaps closed, and one real bug —
frames arriving in the same read as `welcome` were dropped before
`listen()` (exactly the re-attach case); now queued.

## Lessons

- WSL2 distros share ONE network namespace: abstract unix socket names
  (and localhost ports) collide across distros.
- `mkdirSync(dir, { mode })` never changes an existing dir's mode.

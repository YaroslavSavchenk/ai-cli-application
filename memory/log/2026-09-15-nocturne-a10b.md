# 2026-09-15 — Nocturne A10b LANDED: editor pane with file tabs

The user's correction on the A10 Windows check: files must not each become
their own pane; after the first one they show as TABS inside that editor
pane (as the A6 column had), and a split appears only when a tab is dragged
to a pane edge. Confirmed with a mockup; spec `.claude/PLAN-A10b.md`.

## Decisions (user 2026-09-15)

One editor pane per group with an inner file-tab strip (file + read-only
diff tabs, dirty dot, `×`); a Files row adds a tab to the focused editor
pane of the root's folder tab (creates the pane when none; raises when
already open in that tab); drag a tab to a pane edge → new editor pane;
onto another editor pane → move; terminals stay mixable; last tab closes
the pane. Defaults: no strip reorder / bottom-strip drop (each would need
its own chord); a Files row on an editor centre ADDS; chords
ctrl+alt+PageUp/PageDown unshifted (cycle tabs; `[`/`]` are AltGr on NL/BE/
DE), ctrl+alt+m (move to next editor pane, else split beside), ctrl+alt+w
closes the ACTIVE TAB; the count pill keeps counting panes.

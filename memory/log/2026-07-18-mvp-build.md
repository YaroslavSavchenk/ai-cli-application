# 2026-07-18 — MVP built (backend, frontend, launcher)

Same day as [[2026-07-18-project-setup]]: the full MVP was implemented via
three orchestrated workflows running the dev-flow loop (developer →
scope/security/test reviewers in parallel → fixer → re-review).

Landed (commits efa646f, 5ceb552 on origin/main):

- **Backend** — node-pty sessions, 1 MiB ring buffer, replay-then-live WS
  attach, token auth + Host/Origin checks, auto-port discovery file,
  BEL→attention. 1 fix cycle (log growth cap, anti-framing headers).
  23/23 automated tests.
- **Frontend** — "phosphor instrument panel" UI ([[anti-slop-design-direction]]):
  tabs with 1/2/3/4-pane layouts, session launcher (claude presets, model,
  resume, custom), sessions drawer, projects manager + directory browser,
  attention badges, Ctrl+Alt keyboard nav with AltGr guard
  ([[frontend-terminal-quirks]]). 2 fix cycles (missing resume control,
  scrim token, amber single-meaning, stale layout signature). 24/24
  protocol-conformance checks against a live server.
- **Launcher** — launch.ps1/.cmd + start-backend.sh with the hard-won WSL
  facts in [[wsl-interop]] (setsid --fork, nvm sourcing, EdgeCore probe,
  distro prefix resolution). 1 fix cycle (-Status token redaction).
  Verified end-to-end from WSL via powershell.exe, incl. stale-file
  recovery and single-instance behavior.

A session usage limit killed the first frontend attempt mid-run; resumed
via workflow cache with an audit-and-finish brief — worked well.

Backlog (deliberate, recorded, not bugs): poll swallows 401/403 after boot
(no reload panel); -Stop lacks pid-identity guard (pid reuse); attention
events need a broadcast channel for sub-second badges; one-off px values in
app.css + box-shadow tab tick; 400-vs-500 on spawn into a deleted project
dir; WS send-queue backpressure; command args logged verbatim (secrets at
rest); token-oracle nature of GET / for local users.

Still pending: user's manual Windows pass — the 9 verify-terminal checks in
a real browser, Edge --app window appearance, taskbar pinning, cold boot.

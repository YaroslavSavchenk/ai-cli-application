# 2026-09-15 — Nocturne A9 LANDED: drop files and folders from Windows Explorer (visual, mock transport)

User's ask (2026-09-15): drag or copy files/folders from Explorer into the
file system shown in the app, "like Explorer", with the destination always
obvious. Spec `.claude/PLAN-A9.md`; B10 = the functional half (upload
endpoint, security review, copy-to-clipboard via the native host).

## Decisions (user)

Drop targets = Files-panel folder rows AND panes (+ panel root, empty tab);
conflicts asked per drop Explorer-style (`Skip · Replace · Keep both`, one
dialog per drop, choice covers all); no dragging out, but copy-to-clipboard
wanted (B10); a terminal pane of a session WITHOUT a project is not a target
(`This session has no project folder yet.`); TEXT drags onto a terminal are
cancelled (PTY protection). Defaults: `Copy files here…` strip under the
panel header + ctrl+alt+c on a folder row + paste-with-files as the twins;
destination always a NAME; honesty line in every dialog state until B10.

## What landed

- **Phase 0** `ui/drop-model.ts` (DOM-free: counts/sentences, `conflictsOf`,
  Explorer-style `keepBothName`, `planResults`, limits 200 items / 50 MiB as
  sentences), 35 tests.
- **Brief 1** `ui/drop-dialog.ts` (`fd-` card, three states in one card,
  accent outline on `Keep both`, Esc/×/backdrop = Skip, Esc during copying =
  nothing, honesty line per state from one marked call site; real Edge
  render found two defects the fake DOM could not: a blank body band and a
  UA focus ring).
- **Brief 2** `ui/filedrop.ts` (window CAPTURE listeners; `Files` drag ⇒
  `preventDefault()` FIRST, unconditionally, validity via `dropEffect`;
  target order folder row → panel root → pane → empty state; cursor ghost;
  700 ms watchdog — the DnD model re-fires `dragover` only every ~350 ms;
  paste only outside terminals/editables; `installDropGuard()` as the first
  statement of `boot()` so a drop during boot never navigates the app away),
  `files.ts` destinations (`destinationOfPane` follows the Files header's
  order: session → its project → tab root; editor pane → tab root → first
  session's project), `keys.ts` `OPEN_MODAL_SELECTOR` (not the focus-owner
  selector: drawers must not kill pane drops), fake-dom `makeDataTransfer`.
- **Fix cycles** (2, 11 findings, 0 disputed): preventDefault before the
  in-app-drag guard; the strip button remembers the folder row that last
  held focus inside the panel; honesty line in the conflicts state;
  `dropEffect 'none'` on the text-drag cancel; boot guard; row chord
  ctrl+alt+c (Tab order made the strip button unreachable for a nested
  folder); two flash sentences (`session` vs `tab`).

## Review

WebView2 host, Ctrl+V with files on the clipboard while a terminal is
